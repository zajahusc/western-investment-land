# Western Investment Land homepage replica

This folder contains a static single-page recreation of the Western Investment Land homepage.

## Files
- index.html — main homepage markup
- styles.css — visual styling and responsive layout
- script.js — contact form feedback
- CNAME — custom domain target for GitHub Pages

## Deploy to GitHub Pages
1. Create a GitHub repository and push these files.
2. In GitHub, open the repository settings and enable Pages.
3. Choose the main branch and the root folder.
4. Your site will be published at your custom domain once DNS is configured.

## Domain setup
Point the custom domain to GitHub Pages by adding or editing DNS records:
- CNAME record for www -> your-github-username.github.io
- A records for the apex domain (if needed) to GitHub Pages IPs

If you want, I can help you generate the exact DNS entries for the Wix domain once you confirm the GitHub Pages URL.
